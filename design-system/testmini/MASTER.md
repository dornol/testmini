# TestMini UI 기준

Svelte 5 / Tailwind 4 / bits-ui 기반 업무용 QA 제품. ui-ux-pro-max의 Data-Dense Dashboard 지침과 기존 공통 테마를 사용한다. 마케팅용 hero/glassmorphism 추천은 업무 화면과 맞지 않아 채택하지 않는다.

## 공통 규칙

- 기존 semantic 색상 토큰과 Lucide/SVG 아이콘을 재사용한다. 라이트·다크를 함께 검토한다.
- 페이지 제목 24px/굵게, 섹션 제목 18px/중간 굵기, 본문 14px, 보조 정보 12px. 모바일 입력은 16px.
- 일반 버튼·입력·선택은 40px. 밀집 도구·표 내부는 32px, 최소 24px 조작 영역. 터치 입력은 44px 이상.
- 같은 툴바 안에서 컨트롤 크기를 통일한다. 필터 라벨은 입력 위, 하단 정렬. 28px 임의 규격을 새로 추가하지 않는다.
- 페이지 간격 24px, 섹션 간격 16px, 필드 그룹 16~24px, 컨트롤 간격 8px.
- 주요 작업은 한 가지 시각적 우선순위를 갖는다. 보조 작업은 outline/ghost, 삭제는 destructive.
- 목록: 제목·주요 작업 → 검색·필터 → 선택·일괄 작업 → 결과 → 페이지 이동.
- 넓은 표는 표 내부에서 가로 스크롤한다. 페이지 자체는 가로로 넘치지 않는다. 선택·정렬 상태를 보조 기술에 전달한다.
- 긴 제목·URL·프로젝트명은 축소 가능한 컨테이너에서 줄바꿈한다. 꼭 필요한 생략에는 전체 텍스트 접근 경로를 제공한다.
- 폼: 명시적 라벨, 필수 입력, 필드별 오류 및 aria-describedby/aria-invalid. 제출 실패 시 오류 요약에 포커스하고 필드로 이동할 수 있게 한다.
- 저장 중 버튼은 중복 제출을 방지하고 현재 작업을 설명한다. 실패 시 입력을 보존한다.
- 모달/시트: 이름·설명, 내부 스크롤, 키보드 포커스 트랩·복귀, Escape/닫기. 닫기 버튼은 충분한 조작 영역을 갖는다.
- 모든 아이콘 버튼에 동작 이름을 제공한다. 상태는 색상만으로 전달하지 않는다.
- 상태별로 로딩, 최초 빈 상태, 검색 결과 없음, 오류/재시도, 권한 제한을 구별한다.
- 동작은 기존 URL 필터·뒤로 가기·권한·가상 스크롤·지연 로딩을 보존한다.
